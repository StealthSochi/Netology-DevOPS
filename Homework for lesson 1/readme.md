Задача 2
В данный момент я стараюсь использовать следующие решения:

1) Высоконагруженная база данных MySQL, критичная к отказам: использую как минимум пару физических серверов (это надёжно, и нет проблем с ресурсами).
2) Различные веб-приложения стараюсь устанавливать в Docker (Grafana, Nginx и т. д.): их проще обновлять, к тому же это позволяет экономить ресурсы.
3) Windows-системы для бухгалтерского отдела устанавливаю на платформу виртуализации (мне нравится VMware ESXi, но приходится использовать Windows Hyper-V, так как коллегам удобнее работать с Hyper-V). Исключение — база данных 1С: она находится на отдельном сервере, как того требуют специалисты по 1С.
4) Системы, выполняющие высокопроизводительные расчёты на GPU: с такими системами я ещё не сталкивался, но предполагаю, что их можно устанавливать на VMware с пробросом видеокарт в виртуальные машины.

Задача 3

1) Нужно разместить 100 виртуальных машин на базе Linux и Windows для решения общих задач, без особых требований. Инфраструктура преимущественно построена на Windows; требуется реализовать программные балансировщики нагрузки, репликацию данных и автоматизированное создание резервных копий.
   Я использую для таких целей VMware vSphere: в ней очень удобно создавать виртуальные машины и работать с ними.

2) Требуется наиболее производительное бесплатное решение с открытым исходным кодом для виртуализации небольшой инфраструктуры (20–30 серверов) на базе виртуальных машин Linux и Windows.
   Я использую для этих целей Proxmox.

3) Необходимо бесплатное, максимально совместимое и производительное решение для виртуализации Windows-инфраструктуры.
   Я использую Microsoft Hyper-V. Если есть финансирование, выбираю Microsoft Server Datacenter.

4) Необходимо рабочее окружение для тестирования программного продукта на нескольких дистрибутивах Linux.
   С таким я ещё не сталкивался, но предполагаю, что можно использовать Docker.
